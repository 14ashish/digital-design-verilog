# 4-Bit ALU using Verilog HDL

## 📌 Project Description

This project implements a **4-Bit Arithmetic Logic Unit (ALU)** using **Verilog HDL** in **Xilinx Vivado 2024.2**.

---

## ✨ Features

- 4-bit Arithmetic Logic Unit
- Addition
- Subtraction
- AND
- OR
- XOR
- Functional Simulation
- RTL Synthesis
- Implementation
- Timing Analysis
- Power Analysis

---

## 🛠 Tools Used

- Verilog HDL
- Xilinx Vivado 2024.2

---

## 📂 Project Files

- `alu4bit.v`
- `tb_alu4bit.v`
